Frame

Tweak the motion in the actual component

Details

Frame is a motion editor for working React components, built around one question: what should happen when someone changes their mind halfway? You use your real component, interrupt it, and decide what it does at that moment. Export gives you a small runtime that behaves the same way in your app, with no dependency except React.

The stage draws the take at the component's own scale, so the line is the path of its moving edge and each bar is that edge at one 60 Hz frame. The bars and the faint outlines are worked out from the take, they are not measured paints. Drag the round handle to move the interruption, drag the square one to reshape the spring, and the address keeps what you made.

The three components are registered the way any component is, and the studio opens the same three with every state, target and command. Race runs a second copy of the component on another spring or rule, from the same commands. The copy under Export runs the downloaded motion config on the runtime source that the zip holds, inside this page, and the exported build is a separate app made from those files for the expense card with its default motion.

Limits

  • No person has run the usability task, so there is no usability result.
  • All timings come from one Mac in headless browsers, with other work running. They are lab timings, not field data.
  • No physical phone was tested, and touch was emulated.
  • No one using a screen reader has tried it, and no human has reviewed the code.
  • Only registered components work. Elements outside the registered root do not animate.
  • The results above were measured on the expense card. The menu and the sheet use the same runtime and were not part of those runs.
  • Scrubbing back across a viewport change reflows text to the current width.

Method

The report has the tables, raw data and failures. Every number comes from a recorded run.
