Tweak the motion in the actual component

Details

Frame is a motion editor for working React components, built around one question: what should happen when someone changes their mind halfway? You use your real component, interrupt it, and decide what it does at that moment. Export gives you a small runtime that behaves the same way in your app, with no dependency except React.

The studio is the full tool, with every state, target and command. The exported build is a separate app made from those files with the default motion. The preview under Export on this page runs the generated files inside this page, so it always follows what you just changed.

Limits

  • No person has run the usability task, so there is no usability result.
  • All timings come from one Mac in headless browsers, with other work running. They are lab timings, not field data.
  • No physical phone was tested. Touch was emulated.
  • No one using a screen reader has tried it, and no human has reviewed the code.
  • Only registered components work. Elements outside the registered root do not animate.
  • Scrubbing back across a viewport change reflows text to the current width.
