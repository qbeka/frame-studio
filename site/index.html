Change your mind halfway

Press a button, then change your mind before the animation ends. Frame lets you decide what a real React component does at that moment, then exports that behaviour as a small runtime.

The evidence

Every target was met. In a Vite build of this one interaction, Frame added 6.2 KB of gzipped JavaScript and Motion 14.9.1 added 45.1 KB. Motion does far more, and main thread time overlapped, so there is no speed claim here.

How it was checked

  • 120 scripted runs in Chromium, WebKit and Firefox at device scales 1 and 2, with 13,462 comparisons per engine.
  • Spring values against a 50 digit reference, and real browser geometry against an independent numerical solution.
  • Faults were seeded into the export and the replay. The first full run caught 8 of 9, so it was discarded, the workload was fixed and everything was measured again.
  • 46 of 46 seeded logic mutants were caught by the tests.
  • 118 unit tests and 71 browser tests pass on a fresh clone of the public repository.

What this cannot tell you

  • No person has run the usability task, and no human has reviewed the code.
  • No physical phone was tested, and no one using a screen reader has tried it.
  • These are lab timings from one machine with other work running, not field data.
  • Only registered components work. Elements outside the registered root do not animate.
  • Scrubbing back across a viewport change reflows text to the current width.
